# Accessibility

The editor uses native buttons, inputs, fieldsets, and headings. Selection is conveyed with both text and `aria-pressed`; save feedback uses a polite live region; destructive actions have contextual labels; and the preview preserves label/control relationships.

Keyboard users can undo with the platform shortcut, move fields without drag-and-drop, and reach every authoring control in DOM order. Automated Axe checks complement, but do not replace, keyboard and screen-reader review.
